## Ringkasan Eksekutif

Kesan "aneh" pada padding tombol, icon tombol, dan teks tab punya satu akar masalah dan tiga penguat.

**Akar masalah: skala global menyusut dua kali.** Di `app/globals.css`, `html { font-size: 87.5% }` membuat 1rem = 14px. Lalu `@media (min-width:1024px) { html { zoom: 0.8 } }` mengecilkan semuanya lagi. Hasilnya, `text-xs` tampil **8.4px** dan tab `sm` tingginya **20px** dengan padding vertikal sekitar 4px. Desktop malah lebih kecil daripada mobile (390px: zoom 1, teks tab 10.5px, tab 25px).

**Penguat 1: `Button` tidak berfungsi sebagai sistem.** Skala size di cva terbalik dan default-nya terlalu besar. Akibatnya setiap pemanggil menimpa `h-*`, `py-*`, dan `text-*` sendiri, dan sebagian besar tombol akhirnya ditulis sebagai `<button>` mentah.

**Penguat 2: icon tidak punya aturan.** Ukurannya ditentukan per pemanggil, ada dua satuan (`w-*` vs `size={px}`), dan jaraknya kadang `gap`, kadang margin.

**Penguat 3: empat gaya tab berbeda.** Ada GooeyNav, segmented manual, underline, dan pill di hero `/readiness`. Ukurannya berbeda-beda dan semantik ARIA-nya tidak lengkap.

## Daftar Temuan Bernomor

### Kelompok 1: Prioritas TINGGI

#### 01. Skala global menyusut dua kali (root 14px + `zoom: 0.8`)
- **Prioritas:** HIGH
- **Lokasi:** `apps/dashboard/app/globals.css`
  ```css
  html { font-size: 87.5%; /* 14px base rem */ }
  @media screen and (min-width: 1024px) {
    html { zoom: 0.8; }
    body { min-height: 125vh; }
    #dashboard-root-layout { height: 125vh; }
  }
  ```
- **Terukur (desktop):**

  | Kelas | CSS | Visual |
  |---|---|---|
  | `text-xs` | 10.5px | **8.4px** |
  | `text-[11px]` | 11px | 8.8px |
  | `text-[10px]` | 10px | 8.0px |
  | `size-3.5` (icon) | 12.25px | 9.8px |
  | `size-3` (icon) | 10.5px | 8.4px |
  | Tab `sm` | `py-1.5 px-3` | 20px tinggi, padding 4.2/8.4px |

- **Alasan:** teks bold 8.4px ditambah `letter-spacing: -0.015em` di `body` membuat huruf rapat dan menggumpal. Padding 4px terlihat sesak. Ini juga yang membuat padding dan icon terasa "salah" di semua halaman. Ditambah lagi, `zoom` memaksa hack `125vh` pada layout.
- **Rekomendasi (revisi, zoom dipertahankan):** jangan pakai `text-xs`, `text-[10px]`, atau `text-[11px]` untuk label tombol, tab, dan link aksi. Batas bawah label interaktif adalah `text-[13px]` (10.4px visual), dan teks isi `text-base` (11.2px visual). Tinggi kontrol dihitung dari tabel konversi di atas. Skala ini dikunci di `Button` dan `GooeyNav` (Fase 1) supaya pemanggil tidak perlu menghitung ulang.

### Kelompok 2: Prioritas MENENGAH

#### 05. `Button` cva: skala terbalik, default terlalu besar, tanpa aturan icon
- **Prioritas:** MEDIUM
- **Lokasi:** `apps/dashboard/components/ui/button.tsx` L5–38
  ```ts
  size: {
    default: "h-9 px-4 py-2 text-xs",
    sm: "h-9 px-4 text-sm",   // tinggi sama dengan default, teks lebih besar
    md: "h-12 px-6 text-base", // defaultVariants
    lg: "h-14 px-8 text-lg",
    icon: "h-10 w-10",
  },
  ```
- **Alasan:**
  - Tidak ada `[&_svg]` (ukuran atau shrink), jadi icon diatur per pemanggil.
  - Default `md` (h-12) hampir selalu ditimpa `h-auto py-* text-xs`. Contohnya `LatihanSoalView.tsx` L1262: tombol `Mulai Kerjakan Soal` tampil 34px tinggi dengan teks 8.4px.
  - Komponen hanya dipakai di 9 file. `<button>` mentah mendominasi: `CVView.tsx` (117), `AiCvScreenerView.tsx` (47), `LinkedInAnalysisView.tsx` (39), `AiAssistantDrawer.tsx` (32), `ProfileView.tsx` (29), `TrackerView.tsx` (27).
- **Rekomendasi:** lihat Fase 1, langkah 1.

#### 06. Padding dan font-weight tombol tidak punya skala
- **Prioritas:** MEDIUM
- **Terukur:**
  - Untuk tombol berteks `text-xs` ada **8 kombinasi padding** (CSS): `3.5/8.75`, `5.25/10.5`, `5.25/12.25`, `7/12.25`, `7/14`, `8.75/17.5`, `8.75/21`, `10.5/21`. `/scrape-jobs` sendiri punya 7 kombinasi, `/surat-lamaran` 8.
  - Contoh di `/tracker`: `Pengingat` dan `Sinkronisasi` 24px, `Tambah Lamaran` 22px, `Buka Pengingat` 20px, semuanya dalam satu baris pandang.
  - Weight dengan ukuran teks yang sama: 500, 600, 700, 800 (`font-extrabold`), 900 (`font-black`).
- **Rekomendasi:** tombol dan tab memakai `font-semibold` (600), heading 700. Larang override `h-*`, `py-*`, `px-*`, dan `text-*` pada `Button`.

#### 07. Icon di tombol: ukuran dan jarak tidak konsisten
- **Prioritas:** MEDIUM
- **Terukur:**
  - Ukuran icon visual yang ditemukan: 7.0, 8.4, 9.8, 11.2, 16.1, dan 19.7px. Icon 7px ada di `/readiness`.
  - Di kode: `w-4 h-4` ×538, `w-3.5 h-3.5` ×520, `w-3 h-3` ×136, `w-5 h-5` ×153, ditambah `size={16}` ×65, `size={14}` ×53, `size={12}` ×25, `size={13}` ×12. Karena root 14px, `w-4` = 14px sedangkan `size={16}` = 16px, jadi keduanya tidak setara.
  - Jarak icon–teks memakai `gap-*` atau `mr-1.5`/`ml-1` (`LatihanSoalView.tsx` L655, L819, L827, L1009, L1328). Gap yang terukur: 1.75, 3.5, 5.25, dan 7px.
  - Dua sumber icon: `lucide-react` (80 file) dan `components/icons/CustomIcons.tsx` (13 file, API `size={n}`).
- **Rekomendasi:** ukuran icon ditentukan oleh komponen induk (`Button`, `GooeyNav`), bukan oleh pemanggil. Hapus kelas `w-*`/`h-*` dan margin pada icon di dalam tombol.

#### 08. Empat gaya tab, ukuran berbeda, ARIA tidak lengkap
- **Prioritas:** MEDIUM
- **Lokasi dan terukur:**
  - `components/ui/gooey-nav.tsx` (17 pemakaian): `sm` 20px / 8.4px, `xs` 17px / 8.8px (`/misi-cuan`).
  - Segmented manual `BugReportView.tsx` dan `FeatureRequestView.tsx`: `px-3 py-1 rounded-[6px]`, 17px.
  - Underline `OfferingPreparationModal.tsx` L300–345: `border-b-2`.
  - Pill di hero `/readiness`: `4 Dimensi Kesiapan`, `Asesmen Diagnostik Cepat`, dan lain-lain.
  - `role="tablist"` ada di `<ul>`, tetapi item tidak punya `role="tab"`, `aria-selected`, atau `aria-controls`. ArrowRight tidak memindahkan fokus (diuji). `@radix-ui/react-tabs` sudah terpasang tapi tidak dipakai.
  - `py-0.2` di badge tab bukan kelas Tailwind yang valid.
  - Satu nav mencampur tab dengan dan tanpa icon (`CvMatchAnalysisView.tsx` L500). Label tab juga panjang ("Daftar Latihan Soal (Katalog)", "Mode B: Target Lowongan (Tempel JD)").
- **Rekomendasi:** satu komponen tab dengan dua varian resmi (`pill` dan `underline`). Lihat Fase 1, langkah 2.

### Kelompok 3: Prioritas RENDAH
