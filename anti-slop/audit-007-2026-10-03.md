## Yang belum selesai

### Prioritas TINGGI

#### R1. Fokus tidak kembali ke tombol pembuka setelah overlay ditutup
- **Terukur:** 0 dari 13 overlay. Setelah Escape, fokus jatuh ke `<body>`, walaupun tombol pembukanya masih ada di DOM.
- **Penyebab (terverifikasi):** Radix Dialog mode modal mengganti perilaku default dan hanya memfokuskan `context.triggerRef` saat ditutup (`@radix-ui/react-dialog` 1.1.23, `dist/index.mjs` L154–156). Di app ada **29 dialog controlled** (`<Sheet open={...}>`) dan **0** pemakaian `SheetTrigger`/`DialogTrigger`, jadi `triggerRef` selalu kosong.
- **Perbaikan:** bungkus tombol pembuka dengan `<SheetTrigger asChild>` / `<DialogTrigger asChild>`. Untuk overlay yang dibuka dari tempat lain (misalnya dari dalam drawer lain), tambahkan opsi `returnFocusRef` di `SheetContent`/`DialogContent`:
  ```tsx
  onCloseAutoFocus={(e) => { if (returnFocusRef?.current) { e.preventDefault(); returnFocusRef.current.focus(); } }}
  ```

#### R2. Error tracker masih ditemani empty state palsu
- **Terukur** (mock `GET /api/applications` 500): alert "Gagal memuat daftar lamaran" + tombol **Coba lagi** sudah muncul. Tapi di bawahnya tetap tampil "Belum Ada Lamaran, Yuk Mulai!", header "TOTAL: 0", dan banner "Belum ada lamaran yang dicatat di Tracker" (`d3/state-tracker-error.png`).
- **Perbaikan:** saat `errorMessage` dari load ada, sembunyikan empty state, banner pengingat, dan stats (tampilkan `–`). Ini persis pola `AsyncState` yang sudah dibuat, tapi `TrackerView` belum memakainya.

#### R3. GooeyNav lama masih dipakai di 5 halaman
- **Lokasi:** `TrackerView.tsx` L1245, L1272; `LatihanSoalView.tsx` L1160, L1204; `ProfileView.tsx` L652; `MailerView.tsx` L564; `CareerDevelopmentTabs.tsx` L74.
- **Terukur:** tanpa `role="tab"`, tinggi 21px visual (di bawah 24px), dan state aktif hilang di forced-colors.
- **Perbaikan:** migrasi ke `Tabs` (tugas A.3, D.2, D.3, D.1), lalu hapus `gooey-nav.tsx` (L.2).

#### R4. Test otomatis (K7, disetujui) belum ada
- Tidak ada Vitest, tidak ada script `test` di `apps/dashboard/package.json`, dan 0 file test. Tugas T.1, T.2, 1.2.T, 1.3.T, 1.4.T, 1.5.T, 1.6.T, dan 1.7.T belum dikerjakan. Bug R1 adalah contoh yang seharusnya tertangkap oleh test 1.5.T ("fokus kembali ke pembuka").
