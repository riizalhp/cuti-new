## Sisa pekerjaan menuju 100/100

### Prioritas tinggi

1. **Kontras `/scrape-jobs` dan `/cv-screener/report`** masih terlalu banyak gagal. Perlu audit per komponen, bukan global blind replacement.
2. **CTA oranye dengan teks putih** masih tersisa di beberapa halaman. CTA primer harus cobalt atau orange-700 dengan kontras AA.
3. **Lint baseline dan lock-in rule** belum selesai. Source build aman, tetapi kualitas static rule belum 10/10.
4. **Overlay yang belum dapat dipicu** perlu diuji dengan fixture/mock data: Offering, Interview Schedule, CV HRD, dan flow editor CV.

### Prioritas menengah

5. Sisa target <24px: pagination dots, action icons, `/scrape-jobs`, screener report.
6. Hydration mismatch `/cv/[id]` dan `/design-system` harus diuji kembali setelah server stabil.
7. Reduced-motion audit perlu memastikan pulse `/match-cv` tidak berjalan saat `prefers-reduced-motion: reduce`.
8. Empat input dengan focus ring lemah/tidak ada perlu diperbaiki: JobTitleSearchSelect, RoleCombobox, pencarian Latihan Soal, BulletPointListInput.
9. Token radius lama di `globals.css` perlu dipastikan tidak lagi menimpa skala `@theme`.

## Kesimpulan

Pembaruan terbaru berhasil menaikkan skor menjadi **69/100**. Fondasi UI sekarang sudah jauh lebih matang: tabs konsisten, overlay yang dapat diuji memiliki focus return, error tracker tidak lagi menyamar sebagai empty state, dan 17 test otomatis lulus. Bottleneck berikutnya bukan lagi komponen dasar, melainkan **kontras data-dense page, CTA manual, lint legacy, dan fixture untuk overlay yang belum terjangkau akun uji**.
