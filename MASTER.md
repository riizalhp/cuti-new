# MASTER Design System — EMPLOYER

## 1. Brand & Creative Direction

- **Brand Name:** EMPLOYER
- **Category:** AI-Powered Career Platform
- **Primary Positioning:** *"Your career, built around you."*
- **Visual Style:** Cinematic Career Editorial (Fashion/Editorial Campaign × Modern SaaS × Career Platform)
- **Tone:** Aspirational, Optimistic, Intelligent, Youthful, Confident, Personal, Modern, Cinematic.

---

## 2. Design Tokens

### Color Tokens
- **Primary Electric Blue:** `#0000FF` (CTA buttons, active states, match indicators, primary link accents)
- **Electric Blue Light Accent:** `#E6E6FF`
- **Neutral White (Light Ground):** `#FFFFFF`
- **Neutral Paper:** `#F5F5F3`
- **Neutral Surface Dark:** `#111111`
- **Neutral Pure Black:** `#000000`
- **Border Light:** `#E2E2E0`
- **Border Dark:** `#222222`

### Typography Tokens
- **Primary Sans (Headings & Body):** `Inter Tight`, sans-serif
- **Editorial Serif (Italics & Accent Headlines):** `Instrument Serif`, serif
- **Display Brand:** `Bodoni Moda`, serif

### Spacing & Layout Tokens
- **Whitespace Ratio:** Generous asymmetric margins, 120px+ section spacing on desktop
- **Card Corner Radius:** `rounded-2xl` (16px) or sharp `rounded-none` for cinematic frames
- **Border Width:** 1px clean minimal strokes
- **Shadows:** Minimal soft float shadows `box-shadow: 0 20px 40px -15px rgba(0,0,0,0.12)`

---

## 3. Visual & Interaction Thesis

- **Visual Thesis:** High-contrast light & dark editorial layout with massive grotesque typography, crisp electric blue accents (`#0000FF`), floating SaaS artifacts, and cinematic storytelling photography.
- **Interaction Thesis:** Subtle slow scroll parallax, calm number count-up reveals for match scores, smooth layout transitions without playful bounce, fast 150ms interactive hover states with 1.02 scale or underline expand.

---

## 4. 8 Core Journey Pillars

1. **01 BUILD** — Create CV from scratch with AI suggestions.
2. **02 MANAGE** — Store & version control multiple targeted CVs.
3. **03 DISCOVER** — Find relevant opportunities with minimal editorial cards.
4. **04 MATCH** — Compare CV vs Job Description with breakdown (e.g. 87% Match).
5. **05 ADAPT** — Transform & target CV for specific roles without fabricating experience.
6. **06 PIVOT** — Reframe transferable skills into new career paths.
7. **07 APPLY** — Prepare complete application workspace (CV, Match, Cover Letter).
8. **08 TRACK** — Manage application stages via minimal Kanban workspace.

---

## 5. UI Component Rules

- **Minimal Navigation:** Transparent blurred header on hero, solid black/white on scroll.
- **Product Artifacts:** Floating rounded frames representing actual app UI (CV cards, Match gauge, Kanban board), never generic stock screenshots.
- **Micro-Interactions:** Number ticker for match score, hover state color shifts to Electric Blue `#0000FF`.
- **Text Reveal:** Slow, smooth upward fade on section enter.
