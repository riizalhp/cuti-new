## antislop
For UI, copy, people, mobile layout, or code comments work, load the matching antislop skill before starting:
- Core filter, always on: `antislop` ([antislop/SKILL.md](file:///d:/cuti/.agents/skills/antislop/SKILL.md))
- UI / visual: `antislop-ui` ([antislop-ui/SKILL.md](file:///d:/cuti/.agents/skills/antislop-ui/SKILL.md))
- Copy & text: `antislop-copywriting` ([antislop-copywriting/SKILL.md](file:///d:/cuti/.agents/skills/antislop-copywriting/SKILL.md))
- People / accessibility: `antislop-human` ([antislop-human/SKILL.md](file:///d:/cuti/.agents/skills/antislop-human/SKILL.md))
- Mobile / responsive: `antislop-layoutmobile` ([antislop-layoutmobile/SKILL.md](file:///d:/cuti/.agents/skills/antislop-layoutmobile/SKILL.md))
- Code comments: `antislop-code` ([antislop-code/SKILL.md](file:///d:/cuti/.agents/skills/antislop-code/SKILL.md))
Before starting, ask the user when antislop applies: during the work, or after it is done.
